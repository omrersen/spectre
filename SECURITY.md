# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Spectre, please report it responsibly:

1. **Do NOT** create a public GitHub issue
2. Email: omrersen@users.noreply.github.com
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Responsible Use

Spectre is designed for **authorized security testing only**.

- Only scan systems you own or have explicit permission to test
- Comply with all applicable laws and regulations
- Respect rate limits and terms of service
- Report findings responsibly

## AI Features

When using AI-powered features:

- Scan data is sent to LLM providers (OpenAI/Anthropic)
- Do not scan sensitive data you cannot share with these services
- Review AI outputs before acting on them
- AI suggestions are not guaranteed to be accurate
